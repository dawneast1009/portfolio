# 학교 포트폴리오 간소화
요청: 기존 Ruby/HTML 포트폴리오를 노션과 비슷한 문서·첨부파일 중심으로 수정

컴퓨터에서 작성하는 것을 기본으로 하되 360px 이상 모바일에서 같은 내용을 열람·편집한다
공개 주 메뉴는 홈, 내 소개, 진로활동, 주요 활동 및 스킬, 프로젝트의 5개다
내 소개: 강점/흥미/가치관/진로활동 요약
진로활동: 관심 분야/관심 직업/관심 학과
주요 활동 및 스킬: 교과활동/동아리활동/진로활동/사용 프로그램 및 숙련도/기타 강점
프로젝트: 독서/주제탐구보고서/교과 프로젝트/진로 프로젝트/개인 프로젝트/작품 및 결과물
각 소항목에는 제목·내용·링크·공개 상태를 가진 기록 여러 개와 파일 여러 개를 붙인다
숙련도는 자기평가 입문/활용/능숙이며 평가점수로 표시하지 않는다
공개 자료만 방문자에게 표시한다. 편집은 기존 관리자 인증과 CSRF를 사용한다
기존 PStore·계정·프로젝트·파일은 삭제하지 않는다. 이전 프로젝트는 개인 프로젝트 항목에서 접근 가능하다
노션의 실시간 협업·자유 블록 드래그·자동 저장을 구현했다고 표현하지 않는다
무료 Render는 편집 내용이 영구 저장되지 않는다. 상단 안내와 별도 제출용 HTML ZIP으로 구분한다
내보내기는 5페이지와 공개 기록/첨부파일만 포함한다. 계정·세션·PStore·비공개 파일은 절대 포함하지 않는다
ZIP의 상대 링크는 GitHub Pages 프로젝트 하위 경로에서도 동작한다. 배포된 사이트의 URL을 복사할 수 있다
추가 외부 계정 생성, 원격 저장소 변경, 유료 서비스 생성은 수행하지 않는다
