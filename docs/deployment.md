# 배포 안내 — 학교 포트폴리오 버전

작성은 Ruby 서버에서 하고 무료 최종 제출은 공개 HTML 내보내기와 GitHub Pages를 사용합니다.

- 최신 절차: 루트의 `README.md` 4~6절과 `DEPLOY_GITHUB.md`
- 기획서: `PLANNING.md`
- 실제 검증 범위: `docs/verification.md`

이 버전의 `render.yaml`과 `render-free.yaml`은 모두 무료 웹 서비스 설정이며 영구 디스크가 없습니다. 이전 버전의 유료 설정 설명은 적용하지 않습니다. 무료 Render의 로컬 글·업로드 자료는 재시작, 재배포, 유휴 종료 시 사라집니다. 관리자에서 수정한 자료는 GitHub에 자동 저장되지 않습니다.

공개 제출본은 방문자 열람 및 첨부파일 다운로드만 지원합니다. Ruby 관리자 편집 기능이나 편집용 백업은 포함하지 않습니다. 기존 자료의 원본은 서버를 종료한 상태에서 `storage/` 전체를 별도로 보관하세요. 계정이나 실제 storage 자료를 GitHub에 올리지 마세요.

GitHub 저장소 수정, Render 리소스 생성, 외부 공유 URL 생성은 이 패키지를 제작하면서 수행하지 않았습니다.
